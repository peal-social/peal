Peal's first public release: write a post once, schedule it across platforms, and see how it performs, from one place or from your own code. Later releases list each change.

- Publishing to Bluesky, Mastodon, X, Threads, LinkedIn, Facebook Pages, Instagram, TikTok, YouTube, Pinterest and Google Business Profile, to Discord, Telegram and Slack, and to websites and blogs.
- An editor with each platform's limits, media, threads, first comments and polls, a calendar, queues and repeating posts.
- Review before publishing: drafts go to a reviewer, who approves them or asks for changes.
- An inbox for the comments, replies and messages your accounts receive, and analytics on how each post did.
- An HTTP API, webhooks, a command line, an MCP server for AI agents, and SDKs in eight languages.
- Self-hosting with Postgres and an S3-compatible store, under the Functional Source License.
