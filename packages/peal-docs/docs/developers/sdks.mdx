Peal's SDKs call the [API](/developers) from eight languages. They're generated from the same contract as the server, so each method is named after an API operation (`posts.create`, `inbox.messages.send`, `media.importFromUrl`) and each type after an API schema. Unlike the rest of Peal, they're free software under the Apache License 2.0.

## Install [#install]

Each SDK is published to its language's registry:

| Language              | Registry                                                                          | Install                                                   |
| --------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------- |
| TypeScript/JavaScript | [npm](https://www.npmjs.com/package/peal-sdk)                                     | `npm install peal-sdk`                                    |
| Python                | [PyPI](https://pypi.org/project/peal-sdk/)                                        | `pip install peal-sdk` (imported as `peal`)               |
| Go                    | [Go modules](https://pkg.go.dev/github.com/peal-social/peal/packages/peal-sdk/go) | `go get github.com/peal-social/peal/packages/peal-sdk/go` |
| Ruby                  | [RubyGems](https://rubygems.org/gems/peal)                                        | `gem install peal`                                        |
| Java                  | [Maven Central](https://central.sonatype.com/artifact/social.peal/peal)           | `social.peal:peal`                                        |
| PHP                   | [Packagist](https://packagist.org/packages/peal-social/peal)                      | `composer require peal-social/peal`                       |
| .NET                  | [NuGet](https://www.nuget.org/packages/Peal)                                      | `dotnet add package Peal`                                 |
| Rust                  | [crates.io](https://crates.io/crates/peal-sdk)                                    | `cargo add peal-sdk`                                      |

Each package's README shows how to use it, and its `reference.md` lists every method. You'll find both in [the repository](https://github.com/peal-social/peal/tree/main/packages/peal-sdk).

The SDKs call every endpoint that takes a bearer token. That's an [API key](/guides/workspace#api-keys) (`peal_…`), a [partner key](/developers/embedding) (`peal_partner_…`) or an OAuth access token. What only a person does in their own session is left out: exporting or deleting an account, and connected applications.

### Point it at your server [#base-url]

The SDKs send requests to `https://app.peal.social`. On a server of your own, give the client its address ([Base URL](/developers#base-url)) with this option:

| Language           | Option                       |
| ------------------ | ---------------------------- |
| TypeScript and PHP | `baseUrl`, in the options    |
| Python, Ruby, Rust | `base_url`                   |
| Go                 | `option.WithBaseURL`         |
| Java               | `.url(…)` on the builder     |
| .NET               | `BaseUrl` in `ClientOptions` |

### Name the workspace [#workspace]

An API key acts in its own workspace, so a client made with one names none. A partner key or an OAuth token bound to no workspace belongs to none. Give its client the workspace it acts in, and the client sends that workspace's id in the `Peal-Workspace` header on every request ([The workspace of a request](/developers/conventions#workspace)). No method takes a workspace, so make one client per workspace.

| Language                      | Option                               |
| ----------------------------- | ------------------------------------ |
| TypeScript, Python, Ruby, PHP | `workspace`                          |
| Go                            | `option.WithWorkspace`               |
| Java                          | `.workspace(…)` on the builder       |
| .NET                          | `workspace`, after the token         |
| Rust                          | `Peal-Workspace` in `custom_headers` |

The Rust SDK has no option of its own for it, so the header goes in the client's `custom_headers`.

## Check the credential first [#credential]

Start with `GET /api/v1/credential`. It tells you who the key or token is and what it may do, and it reads no data. A key that was revoked or has expired gets 401, so your program finds out whether its key works before it does anything.

What it answers depends on the credential:

| Credential       | Answers      | With                                                         |
| ---------------- | ------------ | ------------------------------------------------------------ |
| An API key       | `apiKey`     | Its name, its workspace, its permissions and when it expires |
| A partner key    | `partnerKey` | Its partner, scopes and permissions                          |
| A person's token | `user`       |                                                              |

Build the client from your key, then ask who it is:

<CodeGroup>

```ts Node.js
import { PealClient } from "peal-sdk";

const peal = new PealClient({ token: process.env.PEAL_API_KEY });

const credential = await peal.credential.get();

if (credential._tag === "apiKey") {
  console.log(credential.workspace.id, credential.permissions);
}
```

## Publish a post, start to finish [#journey]

This program follows the steps of the [Posting API](/developers/posting). It finds the channels, brings an image in from its address, checks the post, sends it with an `Idempotency-Key`, then reads how it went. The key acts in its own workspace, so no call names one.

<CodeGroup>

```ts Node.js
import { randomUUID } from "node:crypto";

import { PealClient } from "peal-sdk";

const peal = new PealClient({ token: process.env.PEAL_API_KEY });

// 1. Where it can go: the channels that can post.
const channels = await peal.channels.list();
const channelIds = channels
  .filter(({ status }) => status._tag === "active")
  .map(({ id }) => id);

// 2. An image that's already online. The server fetches it itself.
const image = await peal.media.importFromUrl({
  url: "https://media.example.com/synthetic/launch.png",
  altText: "A synthetic launch picture",
});

const post = {
  channelIds,
  content: {
    text: "A synthetic post, sent with the SDK.",
    media: [{ mediaId: image.id, altText: "A synthetic launch picture" }],
    overrides: [],
  },
  when: { _tag: "now" as const },
};

// 3. Checked without being made, with every violation at once.
const check = await peal.posts.validate(post);

if (!check.valid) {
  throw new Error(JSON.stringify(check.violations));
}

// 4. Sent under a key: a retry with the same key within 24 hours
// answers this post and makes no second one.
const sent = await peal.posts.create({
  ...post,
  "idempotency-key": randomUUID(),
  wait: "30",
});

// 5. How it went on each channel, once every channel has its result.
const outcome = await peal.posts.outcome({ postId: sent.id });

for (const target of outcome.targets) {
  console.log(target.channelId, target.status, target.permalink);
}
```

```go Go
package main

import (
	"context"
	"crypto/rand"
	"fmt"
	"os"

	peal "github.com/peal-social/peal/packages/peal-sdk/go"
	"github.com/peal-social/peal/packages/peal-sdk/go/client"
	"github.com/peal-social/peal/packages/peal-sdk/go/option"
)

func main() {
	ctx := context.Background()
	client := client.NewClient(option.WithToken(os.Getenv("PEAL_API_KEY")))

	// 1. Where it can go: the channels that can post.
	channels, err := client.Channels.List(ctx)
	if err != nil {
		panic(err)
	}

	var channelIDs []string
	for _, channel := range channels {
		if channel.Status.Active != nil {
			channelIDs = append(channelIDs, channel.ID)
		}
	}

	// 2. An image that's already online. The server fetches it itself.
	image, err := client.Media.ImportFromURL(ctx, &peal.MediaImport{
		URL:     "https://media.example.com/synthetic/launch.png",
		AltText: peal.String("A synthetic launch picture"),
	})
	if err != nil {
		panic(err)
	}

	content := &peal.PostContent{
		Text: "A synthetic post, sent with the SDK.",
		Media: []*peal.MediaAttachment{
			{MediaID: image.ID, AltText: "A synthetic launch picture"},
		},
		Overrides: []*peal.TextOverride{},
	}
	now := &peal.PostTiming{Now: &peal.PostTimingNow{}}

	// 3. Checked without being made, with every violation at once.
	check, err := client.Posts.Validate(ctx, &peal.PostToValidate{
		ChannelIDs: channelIDs,
		Content:    content,
		When:       now,
	})
	if err != nil {
		panic(err)
	}
	if !check.Valid {
		panic(fmt.Sprint(check.Violations))
	}

	// 4. Sent under a key: a retry with the same key within 24 hours
	// answers this post and makes no second one.
	sent, err := client.Posts.Create(ctx, &peal.NewPost{
		ChannelIDs:     channelIDs,
		Content:        content,
		When:           now,
		IdempotencyKey: peal.String(rand.Text()),
		Wait:           peal.String("30"),
	})
	if err != nil {
		panic(err)
	}

	// 5. How it went on each channel, once every channel has its result.
	outcome, err := client.Posts.Outcome(ctx, &peal.OutcomePostsRequest{
		PostID: sent.ID,
	})
	if err != nil {
		panic(err)
	}

	for _, target := range outcome.Targets {
		permalink := ""
		if target.Permalink != nil {
			permalink = *target.Permalink
		}
		fmt.Println(target.ChannelID, target.Status, permalink)
	}
}
```

```java Java
import java.util.List;
import java.util.UUID;
import social.peal.PealClient;
import social.peal.resources.media.requests.MediaImport;
import social.peal.resources.posts.requests.NewPost;
import social.peal.resources.posts.requests.PostToValidate;
import social.peal.types.Channel;
import social.peal.types.Media;
import social.peal.types.MediaAttachment;
import social.peal.types.Post;
import social.peal.types.PostContent;
import social.peal.types.PostTarget;
import social.peal.types.PostTiming;
import social.peal.types.PostTimingNow;
import social.peal.types.PostValidation;

PealClient peal = PealClient.builder()
    .token(System.getenv("PEAL_API_KEY"))
    .build();

// 1. Where it can go: the channels that can post.
List<String> channelIds = peal.channels().list().stream()
    .filter(channel -> channel.getStatus().isActive())
    .map(Channel::getId)
    .toList();

// 2. An image that's already online. The server fetches it itself.
Media image = peal.media().importFromUrl(MediaImport.builder()
    .url("https://media.example.com/synthetic/launch.png")
    .altText("A synthetic launch picture")
    .build());

PostContent content = PostContent.builder()
    .text("A synthetic post, sent with the SDK.")
    .media(List.of(MediaAttachment.builder()
        .altText("A synthetic launch picture")
        .mediaId(image.getId())
        .build()))
    .build();
PostTiming now = PostTiming.now(PostTimingNow.builder().build());

// 3. Checked without being made, with every violation at once.
PostValidation check = peal.posts().validate(PostToValidate.builder()
    .content(content)
    .channelIds(channelIds)
    .when(now)
    .build());

if (!check.getValid()) {
    throw new IllegalStateException(check.getViolations().toString());
}

// 4. Sent under a key: a retry with the same key within 24 hours
// answers this post and makes no second one.
Post sent = peal.posts().create(NewPost.builder()
    .content(content)
    .when(now)
    .channelIds(channelIds)
    .idempotencyKey(UUID.randomUUID().toString())
    .wait("30")
    .build());

// 5. How it went on each channel, once every channel has its result.
Post outcome = peal.posts().outcome(sent.getId());

for (PostTarget target : outcome.getTargets()) {
    System.out.println(target.getChannelId() + " " + target.getStatus() + " "
        + target.getPermalink().orElse(""));
}
```

```rust Rust
// cargo add peal-sdk tokio --features tokio/full
// cargo add uuid --features v4
use peal_sdk::prelude::*;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let peal = PealClient::new(ClientConfig {
        token: std::env::var("PEAL_API_KEY").ok(),
        ..Default::default()
    })?;

    // 1. Where it can go: the channels that can post.
    let channel_ids: Vec<String> = peal
        .channels
        .list(None)
        .await?
        .into_iter()
        .filter(|channel| matches!(channel.status, ChannelStatus::Active { .. }))
        .map(|channel| channel.id)
        .collect();

    // 2. An image that's already online. The server fetches it itself.
    let image = peal
        .media
        .import_from_url(
            &MediaImport {
                url: "https://media.example.com/synthetic/launch.png".to_string(),
                alt_text: Some("A synthetic launch picture".to_string()),
            },
            None,
        )
        .await?;

    let content = PostContent {
        text: "A synthetic post, sent with the SDK.".to_string(),
        media: vec![MediaAttachment {
            media_id: image.id.clone(),
            alt_text: "A synthetic launch picture".to_string(),
        }],
        ..Default::default()
    };

    // 3. Checked without being made, with every violation at once.
    let check = peal
        .posts
        .validate(
            &PostToValidate::builder()
                .channel_ids(channel_ids.clone())
                .content(content.clone())
                .when(PostTiming::now())
                .build()?,
            None,
        )
        .await?;

    if !check.valid {
        return Err(format!("{:?}", check.violations).into());
    }

    // 4. Sent under a key: a retry with the same key within 24 hours
    // answers this post and makes no second one. NewPost has no field
    // for the key, so it goes in the request's headers.
    let sent = peal
        .posts
        .create(
            &NewPost::builder()
                .channel_ids(channel_ids)
                .content(content)
                .when(PostTiming::now())
                .wait("30")
                .build()?,
            Some(RequestOptions::new().additional_header(
                "Idempotency-Key",
                uuid::Uuid::new_v4().to_string(),
            )),
        )
        .await?;

    // 5. How it went on each channel, once every channel has its result.
    let outcome = peal
        .posts
        .outcome(&sent.id, &OutcomeQueryRequest::default(), None)
        .await?;

    for target in outcome.targets {
        println!("{} {} {:?}", target.channel_id, target.status, target.permalink);
    }

    Ok(())
}
```

## Errors and retries [#errors]

Each SDK raises a typed error for each error status (Go and Rust return it). A refused key is the SDK's 401 error, and a missing permission is its 403. The error carries the [envelope](/developers/conventions/errors#errors) the API answered, with its `code`, `message` and `requestId`. Log the request's id, and quote it when you ask for help.

Whether the SDK retries depends on the request:

| Request            | The SDK                                                                                                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET, PUT or DELETE | Retries, with backoff, when the API answers 408, 429 or a 5xx. Each request's options set how many times (`maxRetries`, `max_retries`, `option.WithMaxAttempts`, `MaxRetries`: each README says). |
| POST or PATCH      | Never sends it twice, because the first may have made the post before its answer was lost.                                                                                                        |

To send a POST again safely, give it an `Idempotency-Key` ([Idempotency](/developers/conventions/idempotency#idempotency)). The API then answers with the same post and makes no other.

A key can send {{api-with-en}} requests a minute, or {{api-without-en}} on a billing account without a payment method ([Rate limits](/developers/conventions/rate-limits#rate-limits)).

## Pages [#paging]

You read lists that grow without end a page at a time. Pass `limit` and `cursor`, then pass the answer's `nextCursor` as the next `cursor` until it's `null` ([Paging](/developers/conventions/paging#paging)). The partner API's lists (`/api/v1/partner/workspaces`, `/api/v1/partner/customer-usage`, `/api/v1/partner/overview`) take `before` instead, and answer `next`.

The SDKs pass both as they are. None of them has a helper that reads every page for you, so you write the loop:

<CodeGroup>

```ts Node.js
let cursor: string | undefined;

  const page = await peal.media.list({ limit: "100", cursor });

  for (const media of page.items) {
    console.log(media.id);
  }

  cursor = page.nextCursor ?? undefined;
} while (cursor !== undefined);
```

## Verify a webhook [#webhooks]

The SDKs call the API, but they don't receive [webhooks](/developers/webhooks). Verify each delivery with the [Standard Webhooks](https://www.standardwebhooks.com) library for your language before you act on it. [Verify a delivery](/developers/webhooks/requests#verify) says what's signed. In short:

- The endpoint's secret is `whsec_` followed by base64. It's shown once, when the endpoint is made ([The signing secret](/developers/webhooks/requests#secret)).
- Each delivery carries `webhook-id`, `webhook-timestamp` and `webhook-signature` ([What Peal sends](/developers/webhooks/requests#request)).
- The libraries refuse a timestamp more than five minutes from the present.
- For 24 hours after a rotation, `webhook-signature` holds two signatures, one per secret. The libraries accept either.

Verify the body as it arrived, byte for byte, before you parse it:

<CodeGroup>

```ts Node.js
// npm install standardwebhooks
import { Webhook } from "standardwebhooks";

const webhook = new Webhook(process.env.PEAL_WEBHOOK_SECRET ?? "");

// `rawBody` is the request body as received, a string or a Buffer.
// Throws when the signature or the timestamp is wrong.
const event = webhook.verify(rawBody, {
  "webhook-id": request.headers["webhook-id"],
  "webhook-timestamp": request.headers["webhook-timestamp"],
  "webhook-signature": request.headers["webhook-signature"],
});
```


```go Go
// go get github.com/standard-webhooks/standard-webhooks/libraries
import (
	"io"
	"net/http"
	"os"

	standardwebhooks "github.com/standard-webhooks/standard-webhooks/libraries/go"
)

func handle(w http.ResponseWriter, r *http.Request) {
	webhook, err := standardwebhooks.NewWebhook(os.Getenv("PEAL_WEBHOOK_SECRET"))
	if err != nil {
		http.Error(w, "misconfigured", http.StatusInternalServerError)
		return
	}

	// The request body as received.
	rawBody, err := io.ReadAll(r.Body)
	if err != nil {
		http.Error(w, "unreadable", http.StatusBadRequest)
		return
	}

	if err := webhook.Verify(rawBody, r.Header); err != nil {
		http.Error(w, "invalid signature", http.StatusBadRequest)
		return
	}

	w.WriteHeader(http.StatusNoContent)
}
```
