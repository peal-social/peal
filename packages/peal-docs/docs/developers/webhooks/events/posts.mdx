Each event below lists its fields and shows an example payload. Events that name a channel also carry the [fields of one channel](/developers/webhooks/events#per-channel).

From `post.scheduled` to `post.edit_failed`, an event of a post that has [your own id](/developers/posting#external-id) carries it in `data.externalId`, so you can match the event to your record without reading the post. The field is left out when the post has none, and from events sent before it existed. The approval events don't carry it.

## post.scheduled [#post-scheduled]

A post was scheduled, or moved to another time. A post waiting for an [approval](/guides/posts/review) isn't scheduled yet. It sends `post.approval_requested` instead, and this event only once it's approved.

| Field         | Type   | What it holds                                                                 |
| ------------- | ------ | ----------------------------------------------------------------------------- |
| `workspaceId` | string | The workspace                                                                 |
| `postId`      | string | The post                                                                      |
| `scheduledAt` | string | When it goes out, as an instant in UTC                                        |
| `timeZone`    | string | The IANA time zone it was scheduled in, such as `Europe/Paris`                |
| `targets`     | array  | The channels it goes out on, each with `targetId`, `channelId` and `platform` |

```json title="post.scheduled"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e01",
  "type": "post.scheduled",
  "version": 1,
  "timestamp": "2026-11-09T16:42:10.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "scheduledAt": "2026-11-10T09:00:00.000Z",
    "timeZone": "Europe/Paris",
    "targets": [
      {
        "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
        "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
        "platform": "mastodon"
      },
      {
        "targetId": "019a6f3e-8c2b-7d03-b5c2-0f4e8a1d3c26",
        "channelId": "019a5d12-9b0e-7e44-9d1f-2c3b4a5d6e7f",
        "platform": "bluesky"
      }
    ]
  }
}
```

## post.unscheduled [#post-unscheduled]

| Field         | Type   | What it holds |
| ------------- | ------ | ------------- |
| `workspaceId` | string | The workspace |
| `postId`      | string | The post      |

```json title="post.unscheduled"
  "type": "post.unscheduled",

  "workspaceExternalId": null,
  "data": {

    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01"

```

## post.published [#post-published]

The post went live on the channel.

| Field         | Type           | What it holds                                                                                           |
| ------------- | -------------- | ------------------------------------------------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                                                           |
| `postId`      | string         | The post                                                                                                |
| `targetId`    | string         | The post on that channel                                                                                |
| `channelId`   | string         | The channel                                                                                             |
| `platform`    | string or null | The channel's platform, or null once the channel was disconnected                                       |
| `round`       | integer        | How many times the post was sent there                                                                  |
| `publishedAt` | string         | When it went live, as an instant in UTC                                                                 |
| `permalink`   | string or null | Its address on the platform, when the platform gave one, or the member who confirmed it; null otherwise |

```json title="post.published"
  "type": "post.published",

  "timestamp": "2026-11-10T09:00:03.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
    "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
    "platform": "mastodon",
    "round": 1,
    "publishedAt": "2026-11-10T09:00:02.000Z",
    "permalink": "https://social.example/@peal_example/115512345678901234"
  }
}
```

## post.failed [#post-failed]

The post didn't go out on the channel.

| Field         | Type           | What it holds                                                     |
| ------------- | -------------- | ----------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                     |
| `postId`      | string         | The post                                                          |
| `targetId`    | string         | The post on that channel                                          |
| `channelId`   | string         | The channel                                                       |
| `platform`    | string or null | The channel's platform, or null once the channel was disconnected |
| `round`       | integer        | How many times the post was sent there                            |
| `failedAt`    | string         | When it failed, as an instant in UTC                              |
| `reason`      | string         | Why, one of the codes below                                       |

| `reason`                    | What happened                                                                                                                                      |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `contentRejected`           | The platform refused the post's text or format.                                                                                                    |
| `channelDisconnected`       | The channel was disconnected from the workspace before the post went out. Nothing was sent.                                                        |
| `channelDisabled`           | The channel was turned off before the post went out. Nothing was sent.                                                                             |
| `mediaRemoved`              | One of its images or videos was deleted, or was no longer ready, before the post went out. Nothing was sent.                                       |
| `mediaRejected`             | The platform refused one of its images or videos.                                                                                                  |
| `missed`                    | The server was down at the scheduled time, and the post was too late to send when it came back.                                                    |
| `notPublished`              | A member checked an unconfirmed post on the platform and didn't find it.                                                                           |
| `rateLimited`               | The platform kept limiting Peal until the attempt gave up.                                                                                         |
| `tokenExpired`              | The platform refused the channel's authorization: the channel must be reconnected.                                                                 |
| `unavailable`               | The platform couldn't be reached. Nothing was sent.                                                                                                |
| `appNotAudited`             | The platform takes only some posts from the server's app until it approves it. Nothing was sent.                                                   |
| `quotaExceeded`             | A daily allowance of uploads on the platform stayed used up until the attempt gave up.                                                             |
| `appBillingLimit`           | The platform refused the server's app until its operator pays for it. Nothing was sent.                                                            |
| `planLimit`                 | The workspace's plan had no room for the post when it was due: too many channels, or the month's posts used up. Nothing was sent.                  |
| `partsNotSent`              | Some parts of the post are live, and Peal can't send those after them: it has no post to reply to. It can't be reposted.                           |
| `repliesNotAllowed`         | The first parts are live, and X didn't let this server's app post the rest as replies ([Threads](/guides/posts#threads)). It can't be reposted.    |
| `paymentMethodRequired`     | On a server that bills, X's posts are billed at X's rates, and the billing account has no payment method. Nothing was sent.                        |
| `paymentFailed`             | On a server that bills, X's posts are billed at X's rates, and the billing account's last payment failed. Nothing was sent.                        |
| `perAccountPricingRequired` | On a server that bills, X's posts are billed at X's rates, and the workspace is on a plan from before per-account pricing. Nothing was sent.       |
| `xThreadCut`                | On a server that bills, a thread on X was cut: its first parts are live, and X's meter refused the next one. Repost to send the rest.              |
| `xCeilingReached`           | On a server that bills, the post would have passed the billing account's monthly ceiling for X. Nothing was sent.                                  |
| `forumThreadNameRequired`   | The Discord channel is a forum, each of its posts needs a title, and this post had none ([Discord](/platforms/discord)). Nothing was sent.         |
| `chatMigrated`              | The Telegram group became a supergroup, with a new id. Connect the chat again ([Telegram](/platforms/telegram)). Nothing was sent.                 |
| `cannotPost`                | The app isn't allowed to post in the channel, as when a Slack app isn't in it. Invite the app there ([Slack](/platforms/slack)). Nothing was sent. |

[Notifications](/guides/workspace/notifications#events) explains what to do about each one.

```json title="post.failed"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e04",
  "type": "post.failed",
  "version": 1,
  "timestamp": "2026-11-10T09:00:04.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d03-b5c2-0f4e8a1d3c26",
    "channelId": "019a5d12-9b0e-7e44-9d1f-2c3b4a5d6e7f",
    "platform": "bluesky",
    "round": 1,
    "failedAt": "2026-11-10T09:00:04.000Z",
    "reason": "tokenExpired"
  }
}
```

## post.unconfirmed [#post-unconfirmed]

Peal can't tell whether the post went live on the channel, and it never sends the post again on its own. Someone has to check the platform, then [confirm it or post it again](/guides/posts/schedule#follow-up).

Once a member says what they found, a `post.published` follows for the same `round`, or a `post.failed` with the reason `notPublished`. A repost brings the events of the next round.

| Field         | Type           | What it holds                                                     |
| ------------- | -------------- | ----------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                     |
| `postId`      | string         | The post                                                          |
| `targetId`    | string         | The post on that channel                                          |
| `channelId`   | string         | The channel                                                       |
| `platform`    | string or null | The channel's platform, or null once the channel was disconnected |
| `round`       | integer        | How many times the post was sent there                            |
| `attemptedAt` | string         | When the attempt was made, as an instant in UTC                   |
| `reason`      | string         | Why Peal can't tell, one of the codes below                       |

| `reason`             | What happened                                                                                                                                                          |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `noResponse`         | The request may have reached the platform, and no answer came back.                                                                                                    |
| `unreadableResponse` | An answer came back that Peal couldn't read.                                                                                                                           |
| `interrupted`        | The server stopped during the call, so whether it went out isn't known.                                                                                                |
| `adapterFailure`     | Peal's own code failed during the call, after the request may have left.                                                                                               |
| `stillProcessing`    | The platform took the post and was still processing it when Peal stopped checking.                                                                                     |
| `searchRefused`      | An article's site refused Peal's search for a post an earlier call may have made.                                                                                      |
| `severalOnSite`      | An article's site holds another post of its title, which Peal can't tell from the one it may have made: look, then rename or remove the other before sending it again. |

```json title="post.unconfirmed"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e05",
  "type": "post.unconfirmed",
  "version": 1,
  "timestamp": "2026-11-10T09:00:21.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
    "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
    "platform": "linkedin",
    "round": 1,
    "attemptedAt": "2026-11-10T09:00:01.000Z",
    "reason": "noResponse"
  }
}
```

## post.cancelled [#post-cancelled]

The post was cancelled. `targets` lists the channels it won't go out on. A channel it had already reached keeps its own event.

A channel Peal was sending to at that moment ends with its own event. That's `post.published`, `post.failed` or `post.unconfirmed` if Peal had called the platform, or a `post.cancelled` naming that channel alone if it hadn't.

When someone removes a channel from a post that's waiting for its time, Peal sends a `post.cancelled` naming that channel alone, with `scope` `target`. The post keeps its time and still goes out on its other channels. A `post.scheduled` sent when it moves no longer names that channel, and its `post.finished` lists it as `cancelled`.

| Field         | Type   | What it holds                                                                                                                                                                |
| ------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `workspaceId` | string | The workspace                                                                                                                                                                |
| `postId`      | string | The post                                                                                                                                                                     |
| `cancelledAt` | string | When it was cancelled, as an instant in UTC                                                                                                                                  |
| `scope`       | string | `post` when the post was cancelled; `target` when one channel was taken off a post that still goes out. Left out of events made before it was sent, which are about the post |
| `targets`     | array  | The channels it won't go out on, each with `targetId`, `channelId` and `platform`                                                                                            |

```json title="post.cancelled"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e06",
  "type": "post.cancelled",
  "version": 1,
  "timestamp": "2026-11-09T18:30:00.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "cancelledAt": "2026-11-09T18:30:00.000Z",
    "scope": "post",
    "targets": [
      {
        "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
        "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
        "platform": "mastodon"
      }
    ]
  }
}
```

## post.finished [#post-finished]

Every channel of the post has its result: the post went live there, failed, may have gone out, or was cancelled. `post.published`, `post.failed` and `post.unconfirmed` report each channel as it ends. This event reports the whole post once the last channel has ended, with `outcome`, what the channels add up to.

It can arrive more than once:

- A post sent again on a channel finishes again when that round ends, and brings another `post.finished` with its `round`.
- A member who confirms an unconfirmed channel brings one more, when that changes `outcome`.

An endpoint that listens to some channels receives it when one of the post's channels is among them.

| Field         | Type    | What it holds                                                                                                                                                                                                                                    |
| ------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `workspaceId` | string  | The workspace                                                                                                                                                                                                                                    |
| `postId`      | string  | The post                                                                                                                                                                                                                                         |
| `outcome`     | string  | What its channels add up to: `published` (every channel has it whole), `partiallyPublished` (some do), `unconfirmed` (at least one may have it: check before anything else), `failed` (none has it) or `cancelled` (every channel was cancelled) |
| `finishedAt`  | string  | When it finished, as an instant in UTC                                                                                                                                                                                                           |
| `round`       | integer | The post's latest round: 1, and one more each time one of its channels was sent again                                                                                                                                                            |
| `targets`     | array   | Each channel's result: `targetId`, `channelId`, `platform`, `status` (`published`, `failed`, `unconfirmed` or `cancelled`), `failureReason` ([why](#post-failed) it failed, or null) and `permalink` (its address there, or null)                |

```json title="post.finished"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e1a",
  "type": "post.finished",
  "version": 1,
  "timestamp": "2026-11-10T09:00:04.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "outcome": "partiallyPublished",
    "finishedAt": "2026-11-10T09:00:04.000Z",
    "round": 1,
    "targets": [
      {
        "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
        "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
        "platform": "mastodon",
        "status": "published",
        "failureReason": null,
        "permalink": "https://mastodon.example/@peal_example/113456789012345678"
      },
      {
        "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d16",
        "channelId": "019a5d12-9b0e-7e44-9d1f-2c3b4a5d6e7f",
        "platform": "bluesky",
        "status": "failed",
        "failureReason": "rateLimited",
        "permalink": null
      }
    ]
  }
}
```

## post.unpublished [#post-unpublished]

Peal deleted every part of the post from the channel's platform, as a member, a key or an application asked ([Unpublish a post](/guides/posts/published#unpublish)). The post stays `published` in Peal. Its target gets `removedAt`, and keeps its permalink as a record.

| Field         | Type           | What it holds                                                                  |
| ------------- | -------------- | ------------------------------------------------------------------------------ |
| `workspaceId` | string         | The workspace                                                                  |
| `postId`      | string         | The post                                                                       |
| `targetId`    | string         | The post on that channel                                                       |
| `channelId`   | string         | The channel                                                                    |
| `platform`    | string or null | The channel's platform, or null once the channel was disconnected              |
| `removedAt`   | string         | When the last part was deleted, as an instant in UTC                           |
| `alreadyGone` | boolean        | Whether the platform had a part no longer, as when it was deleted there before |

```json title="post.unpublished"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e21",
  "type": "post.unpublished",
  "version": 1,
  "timestamp": "2026-11-10T09:00:00.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
    "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
    "platform": "mastodon",
    "removedAt": "2026-11-10T09:00:00.000Z",
    "alreadyGone": false
  }
}
```

## post.unpublish_failed [#post-unpublish-failed]

Peal couldn't delete the post from the channel's platform, after all the attempts a deletion makes. `code` says why, as the change's `code` does: `unavailable`, `rateLimited`, `channelUnavailable`, or the platform's own.

The post may still be there, whole or in part. A member can ask again, which deletes the parts that are left.

| Field         | Type           | What it holds                                                     |
| ------------- | -------------- | ----------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                     |
| `postId`      | string         | The post                                                          |
| `targetId`    | string         | The post on that channel                                          |
| `channelId`   | string         | The channel                                                       |
| `platform`    | string or null | The channel's platform, or null once the channel was disconnected |
| `code`        | string         | Why the deletion stopped                                          |
| `failedAt`    | string         | When Peal gave up, as an instant in UTC                           |

```json title="post.unpublish_failed"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e22",
  "type": "post.unpublish_failed",
  "version": 1,
  "timestamp": "2026-11-10T11:22:00.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
    "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
```

## post.edited [#post-edited]

Peal replaced the text of one part of the post on the channel's platform, at someone's request ([Edit a published post](/guides/posts/published#edit-live)). In Peal too, that part's text on the channel is now the new one, and the target has its `editedAt`. The event doesn't carry the text, so read the post if you need it.

| Field         | Type           | What it holds                                                     |
| ------------- | -------------- | ----------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                     |
| `postId`      | string         | The post                                                          |
| `targetId`    | string         | The post on that channel                                          |
| `channelId`   | string         | The channel                                                       |
| `platform`    | string or null | The channel's platform, or null once the channel was disconnected |
| `part`        | integer        | The part edited, from 0 (the post itself)                         |
| `editedAt`    | string         | When the platform took the new text, as an instant in UTC         |

## post.edit_failed [#post-edit-failed]

Peal couldn't edit the post's part on the channel's platform, after all the attempts an edit makes. `code` says why, as the change's `code` does: `postGone` when the platform no longer has the post, `pollNotEditable` for a Mastodon post with a poll, `permissionDenied`, `unavailable`, `rateLimited`, `channelUnavailable`, or the platform's own.

Peal's text is unchanged, and the post most likely still says what it said before.

<Callout
  type="warning"
  title="After unavailable or rateLimited, look at the platform first"
>
  An answer may have been lost, so the platform may show the new text. Look
  there before a member asks again.
</Callout>

| Field         | Type           | What it holds                                                     |
| ------------- | -------------- | ----------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                     |
| `postId`      | string         | The post                                                          |
| `targetId`    | string         | The post on that channel                                          |
| `channelId`   | string         | The channel                                                       |
| `platform`    | string or null | The channel's platform, or null once the channel was disconnected |
| `part`        | integer        | The part Peal was asked to edit, from 0                           |
| `code`        | string         | Why the edit stopped                                              |

## post.approval_requested [#post-approval-requested]

Someone asked for the post to go out in a workspace that asks for [approvals](/guides/posts/review), so it waits. It keeps its time, and no `post.scheduled` is sent until it's approved. Everything an application sends or schedules there starts this way.

The next event tells you what became of it:

- `post.approval_requested` again, with its new `scheduledAt`: it was moved to another time, and still waits.
- [`post.approved`](#post-approved), then `post.scheduled` unless the approval came `late`.
- [`post.changes_requested`](#post-changes-requested): it's a draft again.
- `post.unscheduled`: someone took it back to draft before anyone decided.
- `post.cancelled`: it was cancelled while it waited.
- `post.scheduled` alone: a member who can schedule without an approval scheduled it.

| Field         | Type   | What it holds                                     |
| ------------- | ------ | ------------------------------------------------- |
| `workspaceId` | string | The workspace                                     |
| `postId`      | string | The post                                          |
| `scheduledAt` | string | When it was asked to go out, as an instant in UTC |

```json title="post.approval_requested"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e0a",
  "type": "post.approval_requested",
  "version": 1,
  "timestamp": "2026-11-09T16:40:00.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "scheduledAt": "2026-11-12T08:00:00.000Z"
  }
}
```

## post.approved [#post-approved]

The post was approved. If it was approved in time, it's scheduled, and a `post.scheduled` follows. If it was approved after its time (`late`), nothing goes out late: it's a draft again, and no `post.scheduled` follows.

| Field         | Type    | What it holds                                                                                                         |
| ------------- | ------- | --------------------------------------------------------------------------------------------------------------------- |
| `workspaceId` | string  | The workspace                                                                                                         |
| `postId`      | string  | The post                                                                                                              |
| `by`          | string  | Who approved it, by kind: `member`, `visitor` (someone who came through a review link) or `application`. Never a name |
| `late`        | boolean | Whether its time had passed                                                                                           |

```json title="post.approved"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e0b",
  "type": "post.approved",
  "version": 1,
  "timestamp": "2026-11-09T17:00:00.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "by": "visitor",
    "late": false
  }
}
```
