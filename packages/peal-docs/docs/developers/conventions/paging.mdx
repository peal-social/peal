## Paging [#paging]

You read a list that can grow without end a page at a time, newest first:

1. Send `limit`, the size of a page, in the query.
2. Read the page's `items` and its `nextCursor` in the answer.
3. Pass `nextCursor` as `cursor` to read the next page, and stop when it's `null`.

A cursor is an opaque string. It works for the list it came from, with the same filters. Anywhere else it answers 400 `bad_request`.

Each list has its own page size:

| List                                     | A page holds | At most |
| ---------------------------------------- | ------------ | ------- |
| `GET …/posts/drafts`                     | 20           | 50      |
| `GET …/media`                            | 30           | 100     |
| `GET …/webhooks/{endpointId}/deliveries` | 30           | 100     |
| `GET …/activity`                         | 30           | 100     |
| `GET /api/me/notices`                    | 20           | 100     |

Paths starting with `…` are under `/api/v1`.

Pass the `nextCursor` above to get the next page. The SDKs have no helper that reads every page for you, so each one shows the loop:

<CodeGroup>

```ts Node.js
let cursor: string | undefined;

do {
  const page = await peal.activity.list({ limit: "100", cursor });

  for (const entry of page.items) {
    console.log(entry.operation, entry.status);
  }

  cursor = page.nextCursor ?? undefined;
} while (cursor !== undefined);
```

```python Python
cursor = None

while True:
    page = peal.activity.list(limit="100", cursor=cursor)

    for entry in page.items:
        print(entry.operation, entry.status)

    cursor = page.next_cursor
    if cursor is None:
        break
```

```go Go
var cursor *string

for {
	page, err := client.Activity.List(ctx, &peal.ListActivityRequest{
		Limit:  peal.String("100"),
		Cursor: cursor,
	})
	if err != nil {
		return err
	}

	for _, entry := range page.Items {
		fmt.Println(entry.Operation)
	}

	if page.NextCursor == nil {
		break
	}
	cursor = page.NextCursor
}
```

```ruby Ruby
cursor = nil

loop do
  # Send `cursor` only when there is one.
  query = { limit: "100" }
  query[:cursor] = cursor if cursor

  page = peal.activity.list(**query)

  page.items.each { |entry| puts "#{entry.operation} #{entry.status}" }

  cursor = page.next_cursor
  break if cursor.nil?
end
```

### Lists that take a range [#ranges]

Two lists take a range instead, and answer everything in it at once:

| List                                             | What it answers                                                             | Range                 | Otherwise            |
| ------------------------------------------------ | --------------------------------------------------------------------------- | --------------------- | -------------------- |
| `GET …/posts?from=…&to=…`                        | The posts scheduled between two instants, `from` included and `to` excluded | At most 62 days apart | `invalid_time_range` |
| `GET …/analytics/summary?from=…&to=…&timeZone=…` | A sum of the posts published over a range of days, both included            | 366 days at most      | `invalid_date_range` |

The lists a workspace keeps short come whole, as an array: its channels, members, pending invitations, API keys and webhook endpoints.
