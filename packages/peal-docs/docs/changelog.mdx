What changed in each release of Peal, newest first. A release is named after the day it shipped, in UTC (`v2026.11.16`, then `v2026.11.16.2` for a second one that day), and each change links to its pull request. The same notes are on [GitHub's releases page](https://github.com/peal-social/peal/releases). What each release changed in the API, operation by operation, is in the [API's changelog](/developers/conventions/versioning#changelog).
