Dans ce démarrage rapide, vous allez envoyer une publication sur l’un de vos canaux avec l’API, puis recevoir un webhook quand elle sera partie. Chaque étape montre la même requête dans chaque SDK, avec `curl` et avec la ligne de commande `peal`.

## Avant de commencer [#before]

Il vous faut trois choses :

- Un espace de travail avec au moins un canal connecté dans l’application ([Démarrage rapide](/quickstart), [Connecter des canaux](/guides/channels)).
- `curl`, la [ligne de commande](/developers/cli) ou un [SDK](/developers/sdks) (`npm install peal-sdk` pour Node.js).
- L’adresse de votre instance. Les exemples utilisent `https://api.example.com`, et celle de Peal Cloud est `https://app.peal.social` ([URL de base](/developers#base-url)).

Les identifiants de cette page sont inventés, les vôtres seront donc différents. Les réponses sont abrégées.

<Prompt description="Vous utilisez un agent de code ? Donnez-lui cette consigne." actions={["copy"]}>

Ajoute l’API de Peal à ce projet, en suivant le démarrage rapide de l’API de Peal.

1. Lis la clé d’API dans la variable d’environnement `PEAL_API_KEY`. Ne l’écris jamais en dur et ne la commite jamais.
2. Appelle `GET /api/credential` et garde `workspace.id`.
3. Liste les canaux avec `GET /api/workspaces/{workspaceId}/channels` et demande-moi sur lesquels publier.
4. Vérifie la publication avec `POST /api/workspaces/{workspaceId}/posts/validate`. Si `valid` vaut false, montre-moi chaque violation et arrête-toi.
5. Envoie le même corps à `POST /api/workspaces/{workspaceId}/posts/send`, avec un en-tête `Idempotency-Key` qui contient un nouvel UUID.
6. Crée un point de réception de webhooks avec `POST /api/workspaces/{workspaceId}/webhooks` pour `post.published` et `post.failed`, et conserve son secret de signature, qui n’est montré qu’une fois.

Ce qui part atteint le public des plateformes et ne peut plus être repris depuis Peal. Montre-moi la publication et attends mon accord avant de l’envoyer. Arrête-toi pour me demander si un appel renvoie une erreur.

</Prompt>

## 1. Créer une clé d’API [#key]

<Steps>
  <Step title="Ouvrir les clés d’API">
    Dans l’application, ouvrez les **Paramètres** de l’espace de travail, puis
    **Clés d’API**.
  </Step>
  <Step title="Lui donner ce dont cette page a besoin">
    Nommez la clé et réglez sa durée. Pour cette page, il lui faut
    `channel:read`, `post:read` et `post:schedule`, plus `webhook:manage` pour
    la dernière étape.
  </Step>
  <Step title="La copier">
    Cliquez sur **Créer la clé** et copiez-la. Vous ne la verrez qu’une fois
    ([Clés d’API](/guides/workspace#api-keys)).
  </Step>
</Steps>

Configurez ensuite votre client avec la clé :

<CodeGroup>

```ts Node.js
import { PealClient } from "peal-sdk";

const peal = new PealClient({
  token: process.env.PEAL_API_KEY,
  baseUrl: "https://api.example.com",
});
```

```python Python
import os

from peal import Peal

peal = Peal(token=os.environ["PEAL_API_KEY"], base_url="https://api.example.com")
```

```go Go
import (
	"context"
	"fmt"
	"os"

	peal "github.com/peal-social/peal/packages/peal-sdk/go"
	"github.com/peal-social/peal/packages/peal-sdk/go/client"
	"github.com/peal-social/peal/packages/peal-sdk/go/option"
)

// Le client s’appelle `client`, pour que `peal` reste le paquet des types de
// requête.
client := client.NewClient(
	option.WithToken(os.Getenv("PEAL_API_KEY")),
	option.WithBaseURL("https://api.example.com"),
)
ctx := context.Background()
```

```ruby Ruby
require "peal"

peal = Peal::Client.new(
  token: ENV.fetch("PEAL_API_KEY"),
  base_url: "https://api.example.com"
)
```

```java Java
import social.peal.PealClient;

PealClient peal = PealClient.builder()
    .token(System.getenv("PEAL_API_KEY"))
    .url("https://api.example.com")
    .build();
```

```php PHP
<?php
use Peal\PealClient;

$peal = new PealClient(
    token: getenv('PEAL_API_KEY'),
    options: ['baseUrl' => 'https://api.example.com'],
);
```

```csharp .NET
using Peal;

var peal = new PealClient(
    Environment.GetEnvironmentVariable("PEAL_API_KEY")!,
    new ClientOptions { BaseUrl = "https://api.example.com" }

```

```rust Rust

let peal = PealClient::new(ClientConfig {
    token: std::env::var("PEAL_API_KEY").ok(),
    base_url: "https://api.example.com".to_string(),
    ..Default::default()

```

```bash curl
export PEAL_API_KEY="peal_…"
```

```sh CLI

```

</CodeGroup>

## 2. Vérifier la clé [#credential]

`GET /api/credential` vous dit qui est la clé et ce qu’elle peut faire, sans lire aucune donnée. Copiez son `workspace.id` : toutes les autres requêtes nomment cet espace de travail.

<CodeGroup>

```ts Node.js
const credential = await peal.credential.get();

if (credential._tag === "apiKey") {
  console.log(credential.workspace.id, credential.permissions);
}

const workspaceId = "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90";
```

```python Python
credential = peal.credential.get()

if credential.type == "apiKey":
    print(credential.workspace.id, credential.permissions)

workspace_id = "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90"
```

```go Go
credential, err := client.Credential.Get(ctx)
if err != nil {
	return err
}

if credential.APIKey != nil {
	fmt.Println(credential.APIKey.Workspace.ID, credential.APIKey.Permissions)
}

workspaceID := "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90"
```

```ruby Ruby
# Le SDK renvoie l’identifiant sous forme de hash.
credential = peal.credential.get

puts credential[:workspace][:id] if credential[:_tag] == "apiKey"

workspace_id = "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90"
```

```java Java
import social.peal.types.Credential;

Credential credential = peal.credential().get();

credential.getApiKey().ifPresent(key ->
    System.out.println(key.getWorkspace().getId() + " " + key.getPermissions()));

String workspaceId = "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90";
```

```php PHP
$credential = $peal->credential->get();

if ($credential->isApiKey()) {
    echo $credential->asApiKey()->workspace->id, PHP_EOL;
}

$workspaceId = '7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90';
```

```csharp .NET
var credential = await peal.Credential.GetAsync();

if (credential.IsApiKey)
{
    var key = credential.AsApiKey();
    Console.WriteLine($"{key.Workspace.Id} {string.Join(", ", key.Permissions)}");
}

var workspaceId = "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90";
```

```rust Rust
let credential = peal.credential.get(None).await?;

if let Credential::ApiKey { workspace, permissions, .. } = &credential {
    println!("{} {:?}", workspace.id, permissions);
}

let workspace_id = "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90";
```

```bash curl
curl https://api.example.com/api/credential \
  -H "Authorization: Bearer $PEAL_API_KEY"

export WORKSPACE_ID="7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90"
```

```sh CLI
peal whoami

export PEAL_WORKSPACE="7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90"
```

</CodeGroup>

## 3. Trouver vos canaux [#channels]

Un canal est un compte sur lequel l’espace de travail publie. Connectez-en un dans l’application d’abord ([Connecter des canaux](/guides/channels)). Listez-les ensuite, et vous obtiendrez l’`id` et la `platform` de chacun :

<CodeGroup>

```ts Node.js
const channels = await peal.channels.list({ workspaceId });
```

```python Python
channels = peal.channels.list(workspace_id=workspace_id)
```

```go Go
channels, err := client.Channels.List(ctx, &peal.ListChannelsRequest{WorkspaceID: workspaceID})
```

```ruby Ruby
channels = peal.channels.list(workspace_id: workspace_id)
```

```java Java
import java.util.List;
import social.peal.types.Channel;

List<Channel> channels = peal.channels().list(workspaceId);
```

```php PHP
$channels = $peal->channels->list($workspaceId);
```

```csharp .NET
var channels = await peal.Channels.ListAsync(new ListChannelsRequest { WorkspaceId = workspaceId });
```

```rust Rust
let channels = peal.channels.list(workspace_id, None).await?;
```

```bash curl
curl https://api.example.com/api/workspaces/$WORKSPACE_ID/channels \
  -H "Authorization: Bearer $PEAL_API_KEY"
```

```sh CLI
peal channels list
```

</CodeGroup>

## 4. Vérifier la publication, puis l’envoyer [#post]

`POST …/posts/validate` vous dit si une publication passerait, avec tout ce qui la ferait refuser. Il ne crée rien ([Vérifier une publication](/developers/posting#validate)).

<CodeGroup>

```ts Node.js
const post = {
  workspaceId,
  channelIds: ["0190f3a0-0000-7000-8000-00000000c001"],
  content: { text: "Bonjour depuis l’API", media: [], overrides: [] },
  when: {
    _tag: "at" as const,
    at: "2026-11-16T08:00:00Z",
    timeZone: "Europe/Paris",
  },
};

const check = await peal.posts.validate(post);
```

```python Python
from peal import PostContent, PostTiming_At

post = dict(
    workspace_id=workspace_id,
    channel_ids=["0190f3a0-0000-7000-8000-00000000c001"],
    content=PostContent(text="Bonjour depuis l’API", media=[], overrides=[]),
    when=PostTiming_At(at="2026-11-16T08:00:00Z", time_zone="Europe/Paris"),
)

check = peal.posts.validate(**post)
```

```go Go
channelIDs := []string{"0190f3a0-0000-7000-8000-00000000c001"}
content := &peal.PostContent{
	Text:      "Bonjour depuis l’API",
	Media:     []*peal.MediaAttachment{},
	Overrides: []*peal.TextOverride{},
}
when := &peal.PostTiming{
	At: &peal.PostTimingAt{At: "2026-11-16T08:00:00Z", TimeZone: "Europe/Paris"},
}

check, err := client.Posts.Validate(ctx, &peal.PostToValidate{
	WorkspaceID: workspaceID,
	ChannelIDs:  channelIDs,
	Content:     content,
	When:        when,
})
```

```ruby Ruby
post = {
  workspace_id: workspace_id,
  channel_ids: ["0190f3a0-0000-7000-8000-00000000c001"],
  content: { text: "Bonjour depuis l’API", media: [], overrides: [] },
  when: { _tag: "at", at: "2026-11-16T08:00:00Z", timeZone: "Europe/Paris" }
}

check = peal.posts.validate(**post)
```

```java Java
import social.peal.resources.posts.requests.PostToValidate;
import social.peal.types.PostContent;
import social.peal.types.PostTiming;
import social.peal.types.PostTimingAt;
import social.peal.types.PostValidation;

List<String> channelIds = List.of("0190f3a0-0000-7000-8000-00000000c001");
PostContent content = PostContent.builder().text("Bonjour depuis l’API").build();
PostTiming when = PostTiming.at(PostTimingAt.builder()
    .at("2026-11-16T08:00:00Z")
    .timeZone("Europe/Paris")
    .build());

PostValidation check = peal.posts().validate(workspaceId, PostToValidate.builder()
    .content(content)
    .channelIds(channelIds)
    .when(when)
    .build());
```

```php PHP
use Peal\Posts\Requests\PostToValidate;
use Peal\Types\PostContent;
use Peal\Types\PostTiming;
use Peal\Types\PostTimingAt;

$channelIds = ['0190f3a0-0000-7000-8000-00000000c001'];
$content = new PostContent(['text' => 'Bonjour depuis l’API', 'media' => [], 'overrides' => []]);
$when = PostTiming::at(new PostTimingAt([
    'at' => '2026-11-16T08:00:00Z',
    'timeZone' => 'Europe/Paris',
]));

$check = $peal->posts->validate($workspaceId, new PostToValidate([
    'channelIds' => $channelIds,
    'content' => $content,
    'when' => $when,
]));
```

```csharp .NET
var channelIds = new List<string> { "0190f3a0-0000-7000-8000-00000000c001" };
var content = new PostContent
{
    Text = "Bonjour depuis l’API",
    Media = new List<MediaAttachment>(),
    Overrides = new List<TextOverride>(),
};
var when = new PostTiming(new PostTiming.At(new PostTimingAt
{
    At = "2026-11-16T08:00:00Z",
    TimeZone = "Europe/Paris",
}));

var check = await peal.Posts.ValidateAsync(new PostToValidate
{
    WorkspaceId = workspaceId,
    ChannelIds = channelIds,
    Content = content,
    When = when,
});
```

```rust Rust
let channel_ids = vec!["0190f3a0-0000-7000-8000-00000000c001".to_string()];
let content = PostContent {
    text: "Bonjour depuis l’API".to_string(),
    ..Default::default()
};
let when = PostTiming::at("2026-11-16T08:00:00Z".to_string(), "Europe/Paris".to_string());

let check = peal
    .posts
    .validate(
        workspace_id,
        &PostToValidate::builder()
            .channel_ids(channel_ids.clone())
            .content(content.clone())
            .when(when.clone())
            .build()?,
        None,
    )
    .await?;
```

```bash curl
curl -X POST https://api.example.com/api/workspaces/$WORKSPACE_ID/posts/validate \
  -H "Authorization: Bearer $PEAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "channelIds": ["0190f3a0-0000-7000-8000-00000000c001"],
    "content": { "text": "Bonjour depuis l’API", "media": [], "overrides": [] },
    "when": { "_tag": "at", "at": "2026-11-16T08:00:00Z", "timeZone": "Europe/Paris" }
  }'
```

```sh CLI
peal post "Bonjour depuis l’API" --channel 0190f3a0-0000-7000-8000-00000000c001 \
  --at 2026-11-16T09:00 --time-zone Europe/Paris --dry-run
```

</CodeGroup>

Quand il répond `"valid": true`, envoyez le même corps à `POST …/posts/send`. Avec une `Idempotency-Key`, vous pouvez le renvoyer après un délai dépassé sans publier deux fois ([Idempotence](/developers/conventions/idempotency)).

<CodeGroup>

```ts Node.js
const sent = await peal.posts.send({
  ...post,
  "idempotency-key": "5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90",
});
```

```python Python
sent = peal.posts.send(**post, idempotency_key="5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90")
```

```go Go
sent, err := client.Posts.Send(ctx, &peal.NewPost{
	WorkspaceID:    workspaceID,
	ChannelIDs:     channelIDs,
	Content:        content,
	When:           when,
	IdempotencyKey: peal.String("5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90"),
})
```

```ruby Ruby
sent = peal.posts.send_(**post, idempotency_key: "5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90")
```

```java Java
import social.peal.resources.posts.requests.NewPost;
import social.peal.types.Post;

Post sent = peal.posts().send(workspaceId, NewPost.builder()
    .content(content)
    .when(when)
    .channelIds(channelIds)
    .idempotencyKey("5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90")
    .build());
```

```php PHP
use Peal\Posts\Requests\NewPost;

$sent = $peal->posts->send($workspaceId, new NewPost([
    'channelIds' => $channelIds,
    'content' => $content,
    'when' => $when,
    'idempotencyKey' => '5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90',
]));
```

```csharp .NET
var sent = await peal.Posts.SendAsync(new NewPost
{
    WorkspaceId = workspaceId,
    ChannelIds = channelIds,
    Content = content,
    When = when,
    IdempotencyKey = "5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90",
});
```

```rust Rust
// NewPost n’a pas de champ pour la clé : elle passe dans les en-têtes de la
// requête.
let sent = peal
    .posts
    .send(
        workspace_id,
        &NewPost::builder()
            .channel_ids(channel_ids)
            .content(content)
            .when(when)
            .build()?,
        Some(RequestOptions::new().additional_header(
            "Idempotency-Key",
            "5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90",
        )),
    )
    .await?;
```

```bash curl
curl -X POST https://api.example.com/api/workspaces/$WORKSPACE_ID/posts/send \
  -H "Authorization: Bearer $PEAL_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90" \
  -d '{
    "channelIds": ["0190f3a0-0000-7000-8000-00000000c001"],
    "content": { "text": "Bonjour depuis l’API", "media": [], "overrides": [] },
    "when": { "_tag": "at", "at": "2026-11-16T08:00:00Z", "timeZone": "Europe/Paris" }
  }'
```

```sh CLI
peal post "Bonjour depuis l’API" --channel 0190f3a0-0000-7000-8000-00000000c001 \
  --at 2026-11-16T09:00 --time-zone Europe/Paris \
  --idempotency-key 5f0c2b7e-3d1a-4e58-9a6b-2c4d8e1f7a90
```

</CodeGroup>

La publication est maintenant programmée. Elle apparaît sur le calendrier de l’espace de travail et part à son heure.

<Callout type="info" title="Une publication peut partir tout de suite">
  Avec `"when": { "_tag": "now" }`, la publication part tout de suite. Ajoutez
  `?wait=30` et la réponse attend que chaque canal ait son résultat ([Publier
  tout de suite](/developers/posting#wait)).
</Callout>

## 5. Savoir comment elle s’est passée [#webhook]

Plutôt que de demander, laissez Peal prévenir votre serveur. Créez un point de réception de webhooks pour les événements voulus. La réponse contient son secret de signature, que vous ne verrez qu’une fois : gardez-le pour [vérifier chaque livraison](/developers/webhooks/requests).

<CodeGroup>

```ts Node.js
const endpoint = await peal.webhooks.create({
  workspaceId,
  url: "https://example.com/peal-events",
  eventTypes: ["post.published", "post.failed"],
});
```

```python Python
endpoint = peal.webhooks.create(
    workspace_id=workspace_id,
    url="https://example.com/peal-events",
    event_types=["post.published", "post.failed"],
)
```

```go Go
endpoint, err := client.Webhooks.Create(ctx, &peal.NewWebhookEndpoint{
	WorkspaceID: workspaceID,
	URL:         "https://example.com/peal-events",
	EventTypes: []peal.SubscribableWebhookEventType{
		peal.SubscribableWebhookEventTypePostPublished,
		peal.SubscribableWebhookEventTypePostFailed,
	},
})
```

```ruby Ruby
endpoint = peal.webhooks.create(
  workspace_id: workspace_id,
  url: "https://example.com/peal-events",
  event_types: ["post.published", "post.failed"]
)
```

```java Java
import social.peal.resources.webhooks.requests.NewWebhookEndpoint;
import social.peal.types.SubscribableWebhookEventType;
import social.peal.types.WebhookEndpointSecret;

WebhookEndpointSecret endpoint = peal.webhooks().create(workspaceId, NewWebhookEndpoint.builder()
    .url("https://example.com/peal-events")
    .eventTypes(List.of(
        SubscribableWebhookEventType.POST_PUBLISHED,
        SubscribableWebhookEventType.POST_FAILED))
    .build());
```

```php PHP
use Peal\Types\SubscribableWebhookEventType;
use Peal\Webhooks\Requests\NewWebhookEndpoint;

$endpoint = $peal->webhooks->create($workspaceId, new NewWebhookEndpoint([
    'url' => 'https://example.com/peal-events',
    'eventTypes' => [
        SubscribableWebhookEventType::PostPublished->value,
        SubscribableWebhookEventType::PostFailed->value,
    ],
]));
```

```csharp .NET
var endpoint = await peal.Webhooks.CreateAsync(new NewWebhookEndpoint
{
    WorkspaceId = workspaceId,
    Url = "https://example.com/peal-events",
    EventTypes = new List<SubscribableWebhookEventType>
    {
        SubscribableWebhookEventType.PostPublished,
        SubscribableWebhookEventType.PostFailed,
    },
});
```

```rust Rust
let endpoint = peal
    .webhooks
    .create(
        workspace_id,
        &NewWebhookEndpoint::builder()
            .url("https://example.com/peal-events")
            .event_types(vec![
                SubscribableWebhookEventType::PostPublished,
                SubscribableWebhookEventType::PostFailed,
            ])
            .build()?,
        None,
    )
    .await?;
```

```bash curl
curl -X POST https://api.example.com/api/workspaces/$WORKSPACE_ID/webhooks \
  -H "Authorization: Bearer $PEAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/peal-events",
    "eventTypes": ["post.published", "post.failed"]
  }'
```

```sh CLI
peal webhooks create --url https://example.com/peal-events \
  --events post.published,post.failed
```

</CodeGroup>

Quand la publication part, votre serveur reçoit [`post.published`](/developers/webhooks/events/posts#post-published) pour chaque canal qu’elle a atteint, ou [`post.failed`](/developers/webhooks/events/posts#post-failed) avec la raison.
