Ce qui a changé dans chaque version de Peal, de la plus récente à la plus ancienne. Une version porte le nom du jour où elle a été publiée, en UTC (`v2026.11.16`, puis `v2026.11.16.2` pour une deuxième le même jour), et chaque changement renvoie à sa pull request. Les changements sont décrits en anglais, comme sur [la page des versions sur GitHub](https://github.com/peal-social/peal/releases). Ce que chaque version a changé dans l’API, opération par opération, est dans le [journal des modifications de l’API](/developers/conventions/versioning#changelog).
