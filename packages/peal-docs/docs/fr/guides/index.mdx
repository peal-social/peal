Les guides suivent l’ordre dans lequel un espace de travail en a besoin. Vous connectez d’abord ses canaux, puis vous écrivez et programmez des publications, vous les organisez et les relisez, et vous lisez enfin leurs commentaires et leurs résultats.

Si vous découvrez Peal, commencez par le [démarrage rapide](/quickstart). Sinon, choisissez une partie de l’application :
