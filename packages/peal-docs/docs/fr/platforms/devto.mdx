Comment connecter un compte DEV (dev.to), et ce qu’un article peut y contenir. DEV prend des [articles](/guides/channels/websites), pas des publications.

## En bref [#at-a-glance]

|             |                                                                |
| ----------- | -------------------------------------------------------------- |
| Titre       | 128 caractères au plus                                         |
| Corps       | Écrit en Markdown par Peal, avec ses images                    |
| Étiquettes  | 4 au plus, lettres et chiffres seulement                       |
| Catégories  | Aucune                                                         |
| Sur le site | Publié aussitôt, un brouillon là-bas, ou programmé là-bas      |
| Dépublier   | Remet l’article en brouillon sur DEV : DEV n’en supprime aucun |

## Connecter [#connect]

<Steps>
  <Step title="Créer une clé d’API">
    Sur DEV, ouvrez **Settings**, puis **Extensions**. Sous **DEV Community API
    Keys**, décrivez-la comme Peal et choisissez **Generate API Key**.
  </Step>
  <Step title="La connecter dans Peal">
    Dans **Canaux**, sous **DEV**, collez la clé, puis **Connecter DEV**.
  </Step>
</Steps>

Peal vérifie la clé sur DEV, puis la conserve chiffrée : elle n’est plus jamais affichée. Le canal est le compte à qui appartient la clé. Le connecter de nouveau avec une nouvelle clé remplace l’ancienne. Révoquez la clé sur DEV pour couper l’accès de Peal ; le canal est alors marqué **Reconnecter**.

## Articles [#articles]

- Peal écrit le corps en Markdown, où tout ce que vous avez tapé reste du texte : rien n’en devient balise, tag de gabarit ou intégration de DEV.
- Chaque image part d’abord à l’envoi d’images de DEV, une fois, et l’article la montre depuis DEV. DEV prend par défaut 10 envois par heure et par compte : un article qui a plus d’images attend DEV, et part dès qu’il le peut.
- L’extrait est la description de l’article, l’image mise en avant sa couverture.
- **Programmé là-bas** donne l’heure à DEV, qui le publie alors.
- Peal envoie au plus un appel par seconde à DEV, comme DEV le demande.
- Quand la réponse de DEV se perd, Peal cherche d’abord parmi vos articles celui de même titre et de même corps, et ne l’envoie jamais deux fois.

## Sur votre propre serveur [#self-hosting]

DEV ne demande aucune application sur un serveur auto-hébergé : chaque membre apporte sa clé. Voir [DEV et Hashnode](/self-hosting/platforms#devto-hashnode).
