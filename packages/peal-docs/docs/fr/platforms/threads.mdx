Threads prend une publication seule, sans [fil](/guides/posts#threads) de parties. Chaque option ci-dessous s’applique donc à toute la publication.

## En bref [#at-a-glance]

Voici ce qu’une publication Threads peut contenir :

|                  |                                 |
| ---------------- | ------------------------------- |
| Texte            | {{platform-threads-text-fr}}    |
| Images et vidéos | {{platform-threads-media-fr}}   |
| Parties          | {{platform-threads-parts-fr}}   |
| Formats          | {{platform-threads-formats-fr}} |
| Texte alternatif | {{platform-threads-alt-fr}}     |

Ce que doit être chaque type de fichier est dans [Images et vidéos](/guides/media#platforms).

## Connecter un compte [#connect]

Sous **Threads**, cliquez sur **Connecter Threads** et connectez-vous avec votre compte Threads. Autorisez ensuite Peal à lire votre profil et à publier.

## Options [#options]

Aucune option n’est obligatoire, et Peal n’envoie chacune que si vous la réglez. **Nom dans l’API** est le nom de l’option dans l’API.

| Option                | Nom dans l’API   | Valeurs                                                                                          | Si omise                                                                   |
| --------------------- | ---------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| **Qui peut répondre** | `replyControl`   | `everyone`, `accounts_you_follow`, `followers_only`, `mentioned_only`, `parent_post_author_only` | Tout le monde                                                              |
| **Sujet**             | `topicTag`       | Un sujet sur une ligne, 50 caractères au plus, sans `.` ni `&`                                   | Aucun                                                                      |
| **Aperçu de lien**    | `linkAttachment` | Une adresse commençant par `https://`, sur une publication sans image ni vidéo                   | Threads prévisualise le premier lien d’une publication faite de texte seul |

Si vous réglez un aperçu de lien sur une publication avec des médias, la programmation le refuse.

## Commentaires [#comments]

Peal ne lit pas encore les commentaires sur Threads.

## Sur votre propre serveur [#self-hosting]

Un serveur auto-hébergé propose Threads une fois son application Meta enregistrée : voyez [Threads, Instagram et Pages Facebook](/self-hosting/platforms#meta).
