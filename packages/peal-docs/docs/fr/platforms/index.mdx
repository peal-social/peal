Peal publie sur quinze plateformes, douze réseaux sociaux et trois messageries (Discord, Telegram et Slack). Il publie aussi des articles sur des sites web. La page de chaque plateforme vous dit :

- Comment connecter un compte.
- Ce qu’une publication peut y contenir, et les options qu’elle prend.
- Si Peal lit ses commentaires.
- Ce qu’un serveur auto-hébergé demande pour elle.

## Ce que prend chaque plateforme [#limits]

Peal vérifie ces limites avant qu’une publication parte. Le serveur et chaque client partagent les mêmes règles, si bien que l’éditeur et l’API refusent les mêmes publications. Une plateforme peut encore en refuser davantage, comme un fichier qu’elle ne sait pas lire :

## Sites web [#websites]

Un site web reçoit un [article](/guides/channels/websites) plutôt qu’une publication : un titre, un corps mis en forme, un extrait, des étiquettes et une image mise en avant. Chaque site se connecte à sa façon :

| Site web                                  | Se connecte avec                                             |
| ----------------------------------------- | ------------------------------------------------------------ |
| Un site WordPress à vous                  | Son adresse, un utilisateur et un mot de passe d’application |
| [WordPress.com](/platforms/wordpress-com) | Une connexion sur WordPress.com                              |
| [DEV](/platforms/devto)                   | Une clé d’API                                                |
| [Hashnode](/platforms/hashnode)           | Un jeton d’accès personnel, en offre Pro de Hashnode         |
