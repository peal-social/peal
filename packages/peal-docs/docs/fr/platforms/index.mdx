Peal publie sur quatorze plateformes : onze réseaux sociaux, et trois messageries, Discord, Telegram et Slack. La page de chacune dit :

- comment connecter un compte ;
- ce qu’une publication peut y contenir, et les options qu’elle prend ;
- si Peal lit ses commentaires ;
- ce qu’un serveur auto-hébergé demande pour elle.

## Ce que prend chaque plateforme [#limits]

Voici les limites que Peal vérifie avant qu’une publication parte, d’après les règles que partagent le serveur et chaque client. La plateforme peut en refuser davantage, comme un fichier qu’elle ne sait pas lire.

- [Images et vidéos](/guides/media#platforms) : ce que doit être chaque type de fichier (tailles, durées, proportions).

## Sites web [#websites]

Peal publie aussi des [articles](/guides/channels/websites) sur des sites web : un titre, un corps mis en forme, un extrait, des étiquettes et une image mise en avant, plutôt qu’une publication.

| Site web                                  | Se connecte avec                                             |
| ----------------------------------------- | ------------------------------------------------------------ |
| Un site WordPress à vous                  | Son adresse, un utilisateur et un mot de passe d’application |
| [WordPress.com](/platforms/wordpress-com) | Une connexion sur WordPress.com                              |
| [DEV](/platforms/devto)                   | Une clé d’API                                                |
| [Hashnode](/platforms/hashnode)           | Un jeton d’accès personnel, en offre Pro de Hashnode         |
