Sur Pinterest, une publication devient une épingle sur l’un des tableaux du compte. Peal ne crée aucun tableau : créez celui qu’il vous faut sur Pinterest avant de programmer.

## En bref [#at-a-glance]

Voici ce qu’une épingle peut contenir :

|                  |                                   |
| ---------------- | --------------------------------- |
| Texte            | {{platform-pinterest-text-fr}}    |
| Images et vidéos | {{platform-pinterest-media-fr}}   |
| Parties          | {{platform-pinterest-parts-fr}}   |
| Formats          | {{platform-pinterest-formats-fr}} |
| Texte alternatif | {{platform-pinterest-alt-fr}}     |

Ce que doit être chaque type de fichier est dans [Images et vidéos](/guides/media#platforms).

## Connecter un compte [#connect]

Sous **Pinterest**, cliquez sur **Connecter Pinterest** et connectez-vous sur Pinterest. Autorisez ensuite Peal à :

- Voir vos tableaux et vos épingles.
- Créer des épingles.
- Lire le nom et l’image de votre compte.

Peal ne demande rien sur les tableaux secrets. Il ne les liste donc jamais, et ne peut pas y épingler.

**Canaux** propose Pinterest une fois le serveur Peal configuré pour lui (voir [Sur votre propre serveur](#self-hosting)).

## Options [#options]

L’éditeur propose ces options. **Nom dans l’API** est le nom de l’option dans l’API.

| Option                                   | Nom dans l’API   | Dans l’éditeur                                                           |
| ---------------------------------------- | ---------------- | ------------------------------------------------------------------------ |
| **Tableau**                              | `boardId`        | Obligatoire, l’un de ceux du compte                                      |
| **Section du tableau**                   | `boardSectionId` | Une section du tableau choisi                                            |
| **Titre**                                | `title`          | 100 caractères au plus                                                   |
| **Lien**                                 | `link`           | Là où mène un clic sur l’épingle, commençant par `http://` ou `https://` |
| **Couverture de la vidéo, à la seconde** | `coverSecond`    | La première image sauf choix contraire                                   |
| **Couleur dominante**                    | `dominantColor`  | Comme `#6E7874`                                                          |

Une épingle a un seul texte alternatif, celui du premier fichier. Les images d’un carrousel partagent le titre, la description et le lien de l’épingle.

### Tableaux [#boards]

Sur un canal Pinterest, l’éditeur lit les tableaux du compte sur Pinterest, jusqu’à 500. Une fois l’un d’eux choisi, il lit aussi ses sections.

Un tableau supprimé depuis, ou au-delà des 500 lus, reste choisi et apparaît comme absent de la liste. Quand Pinterest ne répond pas, cliquez sur **Réessayer** pour relire la liste.

## Commentaires [#comments]

Peal ne lit pas encore les commentaires sur Pinterest.

## Sur votre propre serveur [#self-hosting]

Un serveur auto-hébergé propose Pinterest une fois son application enregistrée : voyez [Pinterest](/self-hosting/platforms#pinterest). D’ici là, **Canaux** ne le propose pas.
