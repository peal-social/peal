On Bluesky, you can choose who may reply to a post and keep others from quoting it. Peal writes those settings in the same request as the post.

## At a glance [#at-a-glance]

Here's what a Bluesky post can hold:

|                   |                                 |
| ----------------- | ------------------------------- |
| Text              | {{platform-bluesky-text-en}}    |
| Images and videos | {{platform-bluesky-media-en}}   |
| Parts             | {{platform-bluesky-parts-en}}   |
| Formats           | {{platform-bluesky-formats-en}} |
| Alt text          | {{platform-bluesky-alt-en}}     |

What each file type must be is in [Images and videos](/guides/media#platforms).

## Connect an account [#connect]

Under **Bluesky**, type your handle, such as `you.bsky.social`, to go straight to your server's sign-in page. Or leave it empty to pick the account on Bluesky. Then click **Connect Bluesky**.

**Channels** offers Bluesky once the Peal server is set up for it (see [On your own server](#self-hosting)).

## Options [#options]

None of these is required, and Peal sends each one only when you set it. **API name** is the option's name in the API. **Parts** says what the option applies to in a [thread](/guides/posts#threads).

| Option                                                                          | API name                                             | Values                                                                                                             | Left out   | Parts                             |
| ------------------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------- | --------------------------------- |
| **Languages**                                                                   | `languages`                                          | Up to three language tags, such as `en` or `pt-BR`                                                                 | None named | Every part                        |
| **Content label**                                                               | `contentLabel`                                       | `sexual`, `nudity`, `porn`, `graphic-media`                                                                        | No label   | Every part with images or a video |
| **Who can reply**                                                               | `replies`                                            | `everyone`, `nobody`, or `limited` to those of `replyFollowers`, `replyFollowing` and `replyMentioned` that are on | Everyone   | The thread                        |
| **Your followers**, **Accounts you follow**, **Accounts mentioned in the post** | `replyFollowers`, `replyFollowing`, `replyMentioned` | Yes or no, each; with `replies` limited, one at least                                                              | No         | The thread                        |
| **Keep others from quoting this post**                                          | `disableQuotes`                                      | Yes or no                                                                                                          | No         | Every part                        |

A content label describes the images or the video, so a part without media is sent without it.

Peal writes who can reply and quoting with the post, in one request. A post never goes out without them.

<Accordion>
  <AccordionItem title="A channel connected before Peal asked for reply and quote settings">

Who can reply and quoting only work on an account connected since Peal started asking for them. On a channel connected before, scheduling refuses them, and the channel's [capabilities](/developers#capabilities) say so (`optionNeedsReconnect`). In the composer, such a channel offers neither setting, and says why.

To use them, reconnect the account on the **Channels** page. Nothing else changes.

  </AccordionItem>
  <AccordionItem title="The account's server refuses the settings">

Sometimes Peal can't read the channel's scopes, and the account's server then refuses these settings. The post isn't sent: the channel shows **Failed**, with the code `optionRefused`, and Peal doesn't send it again.

Reconnect the account, or leave the settings out, and post it again.

  </AccordionItem>
</Accordion>

## Comments [#comments]

Peal reads the comments under your published posts on Bluesky, and you can answer them from Peal. See [Inbox](/guides/engage/inbox#other-platforms).

## On your own server [#self-hosting]

A self-hosted server offers Bluesky once its app is registered: see [Bluesky](/self-hosting/platforms#bluesky). Until then, **Channels** doesn't offer it.
