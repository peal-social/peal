Mastodon works on any server, with nothing for an operator to set up. You connect an account by its server's name, and Peal registers itself there the first time.

## Connect an account [#connect]

Under **Mastodon**, type the account's server, such as `mastodon.social`, or the account's own address, such as `@you@mastodon.social`. Then click **Connect Mastodon**.

Peal works with any Mastodon server on the public internet that it can reach over HTTPS. The first time someone connects an account on a server, Peal registers itself there as an application. It asks to:

- Read the account's profile.
- Publish posts and media.
- Read the account's posts back, for their counts in [analytics](/guides/engage/analytics).

<Callout type="info" title="Older channels need reconnecting for analytics">
  An account connected before Peal asked to read its posts keeps posting as it
  did. Reconnect it to grant that permission too.
</Callout>

## Options [#options]

None of these is required, and Peal sends each one only when you set it. **API name** is the option's name in the API. **Parts** says whether, in a [thread](/guides/posts#threads), the option goes with every part or with the first part only.

| Option                          | API name         | Values                                                                     | Left out              | Parts      |
| ------------------------------- | ---------------- | -------------------------------------------------------------------------- | --------------------- | ---------- |
| **Who can see this post**       | `visibility`     | `public`, `unlisted` (quiet public), `private` (followers only)            | The account's default | Every part |
| **Content warning**             | `contentWarning` | One line, 500 characters at most                                           | None                  | Every part |
| **Mark the media as sensitive** | `sensitive`      | Yes or no                                                                  | The account's default | Every part |
| **Language**                    | `language`       | A code of two or three lower-case letters, such as `fr`                    | The account's default | Every part |
| **Who can quote this post**     | `quotePolicy`    | `public`, `followers`, `nobody`; only with `visibility` public or unlisted | The account's default | Every part |

### How Mastodon treats them [#options-behaviour]

A content warning counts toward the post's character limit, along with the text. On a Mastodon channel, the 500 characters cover the warning and the text together, on every part, and the composer counts them that way. A content warning also marks the post sensitive, whatever **Mark the media as sensitive** says.

Servers older than Mastodon 4.5 ignore the quote policy. Nobody can quote a followers-only post, whatever its policy says.

Peal doesn't offer private mentions, because it publishes posts.

## Comments [#comments]

Peal reads the comments under your published posts on Mastodon, and you can answer them from Peal. See [Inbox](/guides/engage/inbox#other-platforms).

## On your own server [#self-hosting]

Mastodon needs no setup. Peal registers itself as an application on each Mastodon server the first time someone connects an account there.
