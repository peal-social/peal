Threads takes a post on its own, without a [thread](/guides/posts#threads) of parts, so every option below applies to the whole post.

## At a glance [#at-a-glance]

Here's what a Threads post can hold:

|                   |                                 |
| ----------------- | ------------------------------- |
| Text              | {{platform-threads-text-en}}    |
| Images and videos | {{platform-threads-media-en}}   |
| Parts             | {{platform-threads-parts-en}}   |
| Formats           | {{platform-threads-formats-en}} |
| Alt text          | {{platform-threads-alt-en}}     |

What each file type must be is in [Images and videos](/guides/media#platforms).

## Connect an account [#connect]

Under **Threads**, click **Connect Threads** and sign in with your Threads account. Then allow Peal to read your profile and publish.

## Options [#options]

None of these is required, and Peal sends each one only when you set it. **API name** is the option's name in the API.

| Option            | API name         | Values                                                                                           | Left out                                                |
| ----------------- | ---------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| **Who can reply** | `replyControl`   | `everyone`, `accounts_you_follow`, `followers_only`, `mentioned_only`, `parent_post_author_only` | Everyone                                                |
| **Topic**         | `topicTag`       | One topic on one line, 50 characters at most, without `.` or `&`                                 | None                                                    |
| **Link preview**  | `linkAttachment` | An address starting with `https://`, on a post without images or video                           | Threads previews the first link of a post of text alone |

If you set a link preview on a post with media, scheduling refuses it.

## Comments [#comments]

Peal doesn't read comments on Threads yet.

## On your own server [#self-hosting]

A self-hosted server offers Threads once its Meta app is registered: see [Threads, Instagram and Facebook Pages](/self-hosting/platforms#meta).
