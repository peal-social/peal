Peal publishes [articles](/guides/channels/websites) to WordPress, wherever the site runs. A site takes articles, not posts: a title, a formatted body, an excerpt, tags, categories and a featured image.

## Which page to read [#which-page]

| Your site                                  | How Peal reaches it                             | Read                                                          |
| ------------------------------------------ | ----------------------------------------------- | ------------------------------------------------------------- |
| On WordPress.com, or a Jetpack site        | Signing in on WordPress.com                     | [WordPress.com](/platforms/wordpress-com)                     |
| A WordPress site of your own (self-hosted) | Its address, a user and an application password | [Connect a WordPress site](/guides/channels/websites#connect) |

## What is the same on both [#same]

An article goes out at once, as a draft on the site, or at a time you choose, and you can unpublish it later. The [websites guide](/guides/channels/websites) says how to write one and what each site keeps.
