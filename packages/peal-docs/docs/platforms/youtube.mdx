A YouTube post is one video, with its title and the post's text as its description. You need a YouTube channel before you connect, because a Google account without one connects nothing.

## At a glance [#at-a-glance]

| ----------------- | ------------------------------- |

## Connect a channel [#connect]

<Steps>
  <Step title="Sign in with Google">
    Under **YouTube**, click **Connect YouTube** and sign in with Google.
  </Step>
  <Step title="Pick the channel">
    If your Google account manages several channels, its brand accounts'
    included, Google's account chooser lists them. Each connection is one
    channel.
  </Step>
  <Step title="Allow Peal">
    Allow Peal to upload videos and to see your YouTube account. It reads the
    channel's name and picture, its videos' processing and their counts, and
    changes nothing else. If you untick either permission, the connection is
    refused.
  </Step>
</Steps>

A Google account without a channel connects nothing, so create the channel on YouTube first.

**Channels** offers YouTube once the Peal server is set up for it (see [On your own server](#self-hosting)).

## Options [#options]

The composer shows these first. **API name** is the option's name in the API.

| Option                       | API name                 | In the composer                                      |
| ---------------------------- | ------------------------ | ---------------------------------------------------- |
| **Title**                    | `title`                  | Required: 100 characters at most, without `<` or `>` |
| **Made for kids**            | `madeForKids`            | Required, with no default                            |
| **Visibility**               | `privacy`                | Public unless you choose otherwise                   |
| **Tags**                     | `tags`                   | 500 characters in all                                |
| **Category number**          | `categoryId`             |                                                      |
| **Notify subscribers**       | `notifySubscribers`      | On                                                   |
| Altered or synthetic content | `containsSyntheticMedia` |                                                      |

Peal sends each of the other options only when you set it. Some apply only to some media: the composer shows them for those, and scheduling refuses them on another post.

| Option                                    | API name              | Values                                                             | Left out                |
| ----------------------------------------- | --------------------- | ------------------------------------------------------------------ | ----------------------- |
| **Thumbnail**                             | `thumbnailMediaId`    | A JPEG or PNG image of the [library](/guides/media), 8 MiB at most | The frame YouTube picks |
| **License**                               | `license`             | `youtube` or `creativeCommon`                                      | The channel's default   |
| **Embedding allowed**                     | `embeddable`          | Yes or no                                                          | The channel's default   |
| **Public statistics**                     | `publicStatsViewable` | Yes or no                                                          | The channel's default   |
| **Language of the title and description** | `defaultLanguage`     | A language tag, such as `en` or `pt-BR`                            | None named              |
| **Recording date**                        | `recordingDate`       | A day, as `2026-11-27`                                             | None                    |

### Thumbnails [#thumbnails]

YouTube sets a thumbnail once the video is uploaded, and only on a channel it allows custom thumbnails. When it doesn't, or refuses the image, the video is published anyway, with YouTube's own thumbnail. The post's page says **The thumbnail was not set**, and in the API the post's target holds `thumbnailNotSet: true`.

Each thumbnail draws on the Google project's general quota, so Peal sets up to `YOUTUBE_DAILY_THUMBNAILS` thumbnails a day for the whole server (see [environment variables](/self-hosting/environment-variables)). Past that, a video goes out with YouTube's thumbnail.

## Comments [#comments]

Peal reads the comments under your published videos, and you can answer them from Peal. See [Inbox](/guides/engage/inbox#youtube).

## On your own server [#self-hosting]

A self-hosted server offers YouTube once its app is registered: see [YouTube](/self-hosting/platforms#youtube). Until then, **Channels** doesn't offer it.
