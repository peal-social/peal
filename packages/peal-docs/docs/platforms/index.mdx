Peal posts to fourteen platforms: eleven social networks and three chats (Discord, Telegram and Slack). It also publishes articles to websites. Each platform's page tells you:

- How to connect an account.
- What a post there can hold, and the options it takes.
- Whether Peal reads its comments.
- What a self-hosted server needs for it.

## Websites [#websites]

A website gets an [article](/guides/channels/websites) rather than a post: a title, a formatted body, an excerpt, tags and a featured image. Each site connects its own way:

| Website                                   | Connects with                                   |
| ----------------------------------------- | ----------------------------------------------- |
| A WordPress site of your own              | Its address, a user and an application password |
| [WordPress.com](/platforms/wordpress-com) | Signing in on WordPress.com                     |
| [DEV](/platforms/devto)                   | An API key                                      |
| [Hashnode](/platforms/hashnode)           | A personal access token, on Hashnode's Pro plan |
