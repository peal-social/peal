Peal posts to thirteen platforms: eleven social networks, and two chats, Discord and Telegram. Each platform's page says:

- how to connect an account;
- what a post there may hold, and the options it takes;
- whether Peal reads its comments;
- what a self-hosted server needs for it.

## What each platform takes [#limits]

## Websites [#websites]

Peal also publishes [articles](/guides/channels/websites) to websites: a title, a formatted body, an excerpt, tags and a featured image, rather than a post.

| Website                                   | Connects with                                   |
| ----------------------------------------- | ----------------------------------------------- |
| A WordPress site of your own              | Its address, a user and an application password |
| [WordPress.com](/platforms/wordpress-com) | Signing in on WordPress.com                     |
| [DEV](/platforms/devto)                   | An API key                                      |
| [Hashnode](/platforms/hashnode)           | A personal access token, on Hashnode's Pro plan |
